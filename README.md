# SIDE B · 独立黑胶唱片店（虚构演示站点）

一个可商业化的黑胶唱片购物网站演示：首页是一面可以**横向拖动的唱片墙**，深棕木材 × 奶油纸 × 唱片黑 × 酒红的复古视觉。**所有唱片、音乐人、曲目、封面与试听音频均为原创虚构内容**，不含任何真实音乐作品。

## 功能

- **唱片墙**：鼠标按住拖动（带惯性）/ 触屏滑动 / 滚轮横移 / 箭头按钮；悬停时黑胶从封套缓慢滑出并旋转，浮出纸片卡（歌手 / 年份 / 曲风 / 曲目数 / 版本 / 价格）
- **筛选**：曲风 chips + 年代 / 价格档 / 品相（全新未拆、全新拆封、二手）/ 排序（店主推荐、价格、年代）
- **商品详情**：点击封面抽出唱片并旋转；曲目表（A/B 面）；碟片颜色样本；版本与品相（Goldmine 分级说明）；库存状态；限量编号发售进度条（已售 / 剩余编号区间）；同好推荐
- **试听**：每张唱片 12 秒自制片段（WAV，按曲风合成：爵士摇摆 / 电子脉冲 / 民谣拨弦 / 摇滚 riff / 放克电钢 / 嘻哈 boom-bap + 黑胶炒豆声）；文件缺失时自动回退到浏览器合成音源
- **收藏夹**：心形收藏 + 独立抽屉管理
- **购物车抽屉**：数量增减、移除、小计 / 优惠 / 运费（满 ¥350 免运费）
- **优惠码**：`SIDEB10` 全场 9 折 · `FIRSTSPIN` 满 ¥100 减 ¥20 · `B面彩蛋` 满 ¥233 减 ¥33 · `FREESHIP` 免运费
- **模拟结算**：收货信息校验 → 支付方式（虚构）→ 订单确认 → 生成订单号（不产生真实交易）
- 状态持久化（localStorage），桌面 / 手机自适应

## 目录结构

```
index.html          页面骨架
css/style.css       全部样式（木纹 / 纸张质感 / 唱片交互）
js/data.js          ★ 唯一数据源：商品、曲目、优惠码、素材路径
js/app.js           路由、唱片墙、筛选、购物车、结算、试听播放器
assets/covers/*.svg 封面（每个唱片一张，文件名 = data.js 中的 cover 字段）
assets/audio/*.wav  试听片段（文件名 = preview 字段）
tools/gen-covers.mjs  封面生成器：node tools/gen-covers.mjs
tools/gen-audio.mjs   试听合成器：node tools/gen-audio.mjs
```

## 替换真实内容

1. **商品数据**：编辑 `js/data.js`（唱片元信息、曲目、价格、库存、限量编号都在 `records` 数组）
2. **封面**：把真实封面图放入 `assets/covers/` 并把 `record.cover` 改为对应文件名（支持 jpg/png/webp/svg，正方形）
3. **试听**：把真实片段放入 `assets/audio/` 并更新 `record.preview`（mp3/wav/ogg 均可）
4. **换域名 / 子路径**：无需构建，纯静态 + hash 路由，任意静态托管直接可用
5. 优惠码在 `js/data.js → promoCodes` 中维护

## 本地运行

```bash
cd side-b
python3 -m http.server 8931
# 打开 http://127.0.0.1:8931/
```

## 技术说明

- 纯原生 HTML/CSS/JS，无构建、无依赖；`color-mix()` 需要较新的浏览器（2023+）
- 唱片滑出 / 旋转为纯 CSS transform 过渡与动画
- 音频由 `tools/gen-audio.mjs` 以纯 Node 合成（无采样素材）
